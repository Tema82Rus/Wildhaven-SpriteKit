# Журнал занятий Wildhaven

## 1.1 · Настройка проекта

- Создали iOS-проект в Xcode. Приложение стартует со SwiftUI-экрана, минимальная версия — iOS 27.2, поддерживаются обе горизонтальные ориентации.
- Пользователь запустил приложение и проверил обе ориентации. В передаче занятия зафиксирована успешная контрольная сборка для iOS Simulator.
- Изменения в `develop`. [PR №1](https://github.com/Tema82Rus/Wildhaven-SpriteKit/pull/1)

## 1.2 · Первая сцена SpriteKit

- Показали `GameScene` в SwiftUI через `SpriteView`. Сцена рисует серый фон и оранжевый квадрат 64 × 64 пункта по центру.
- Разобрали дерево узлов, размер сцены, координаты, `anchorPoint` сцены и спрайта, а также порядок отрисовки через `zPosition`.
- Пользователь увидел фон и квадрат в симуляторе, проверил смещение на `(30, 40)` вправо и вверх, затем подтвердил центрирование. Codex собрал итоговый код для iPhone 18 Pro Max с iOS 27.2.
- Изменения в `develop`. [PR №2](https://github.com/Tema82Rus/Wildhaven-SpriteKit/pull/2)
