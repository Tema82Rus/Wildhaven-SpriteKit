# План разработки Wildhaven

Шесть спринтов по пять занятий. На занятие отводим 30–60 минут.
Отмечаем занятие выполненным после проверки результата и записываем итог в [журнал занятий](docs/LEARNING_LOG.md).

## Спринт №1. Основы SpriteKit и управление персонажем

Цель: запустить игру и получить управляемого персонажа.

### 1.1 · Настройка проекта

- [x] Занятие завершено. [PR №1](https://github.com/Tema82Rus/Wildhaven-SpriteKit/pull/1)

- Проверить Xcode, Swift, доступные симуляторы и Git.
- Создать новый iOS-проект со SwiftUI.
- Разобрать структуру Xcode-проекта.
- Создать публичный репозиторий GitHub после согласования названия.
- Настроить GitFlow, README и .gitignore.
- Выполнить первый запуск приложения.

Теория: target, scheme, bundle identifier, Git-репозиторий.

### 1.2 · Первая сцена SpriteKit

- [x] Занятие завершено. [PR №2](https://github.com/Tema82Rus/Wildhaven-SpriteKit/pull/2)

- Подключить SpriteKit через SpriteView.
- Создать GameScene.
- Отобразить фон и простую геометрическую фигуру.
- Разобрать SKScene, SKNode, SKSpriteNode.
- Изучить координаты, anchorPoint, zPosition и размеры сцены.

### 1.3 · Персонаж

- [ ] Занятие завершено

- Создать PlayerNode.
- Добавить временное изображение персонажа.
- Разобрать дерево игровых объектов.
- Изучить позиционирование и направление движения.

### 1.4 · Управление и игровой цикл

- [ ] Занятие завершено

- Создать простой виртуальный джойстик.
- Связать управление с движением персонажа.
- Изучить update(), deltaTime и частоту кадров.
- Нормализовать диагональное движение.
- Ограничить перемещение границами стартовой территории.

### 1.5 · Камера и проверка

- [ ] Занятие завершено

- Подключить SKCameraNode.
- Реализовать следование камеры за персонажем.
- Проверить управление на симуляторе.
- При наличии устройства проверить ощущения на iPhone.
- Провести код-ревью и оформить Pull Request.

Результат: персонаж перемещается по сцене, камера следует за ним.

Версия: v0.1.0.
