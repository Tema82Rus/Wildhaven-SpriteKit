# Wildhaven

Учебный прототип 2D-игры на SwiftUI и SpriteKit.

## Запуск

1. Открой `Wildhaven/Wildhaven.xcodeproj` в Xcode.
2. Выбери симулятор с iOS 27.2.
3. Нажми ⌘R.
